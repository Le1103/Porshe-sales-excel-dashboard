Análise de Vendas da Porsche — Dashboard em Excel

 Descrição do Projeto
Este projeto consiste na higienização, tratamento e análise visual de uma base de dados de vendas de veículos da marca Porsche. O objetivo principal foi transformar dados brutos em insights de negócio através de Tabelas Dinâmicas e Gráficos Dinâmicos no Microsoft Excel.

---

 Perguntas de Negócio Respondidas

1 Qual é o faturamento total por modelo da Porsche?*
   - Identificação dos modelos topo de linha que mais geram receita para a marca.
2 Qual é a distribuição das vendas por método de pagamento?
   - Análise do comportamento de compra dos clientes (ex.: Transferência Bancária, Cartão de Crédito, Financiamento).
3 Qual é o volume de faturamento por ano do modelo (2020–2026)?*
   - Avaliação da participação dos veículos mais recentes em comparação com os modelos de anos anteriores.

---

Processo de Tratamento de Dados (Data Cleaning)
- Substituição de Separadores Decimais: Conversão do ponto (.) por vírgula (,) no campo de preços (SalesPriceSanitized) para leitura numérica adequada no Excel.
- Formatação de Campos:* Definição correta dos tipos de dados (Texto, Moeda e Números inteiros).
- Consolidação:* Criação de Tabelas Dinâmicas segregadas por pergunta analítica.
